# Additional test modes — approval templates

This document is a planning artifact for modes that are not implemented in the
application. It does not authorize a methodology change, user-facing copy, or
new test behavior. A project owner and scientific/methodological owner must
complete and approve a mode's template before implementation begins.

## Common acceptance gate

For every mode below, the completed specification must identify a named owner,
be approved before code changes, and include executable acceptance examples.
Legacy material may be attached as comparison evidence only; it is not approval
for behavior.
